# Judy Roadmap & Capabilities

## Phase 1 (Completed)
- PySide6 executive glassmorphism desktop shell with 5 dedicated functional tabs.
- Continuous wake-word listener on "Judy" with SAPI5 local text-to-speech feedback.
- Automated client lead finder engine with web scraping and SQLite prospecting database.
- Outreach email generator with cold pitch templates, direct SMTP sending, and system mail launcher.
- Desktop and system diagnostics automation (CPU, RAM, disk, IP, app launcher, PowerShell runner).
- Local SQLite FTS document index for PDFs, DOCXs, TXTs, and CSVs.

## Phase 2
- Playwright headless browser automation for deeper client prospect research.
- Advanced multi-step planning and autonomous lead outreach sequences.
- Local sentence-transformers embeddings for semantic document search.
- Native Windows installer bundling with Inno Setup.
